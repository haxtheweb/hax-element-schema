HAXElementSchema is the lightweight object format HAX uses as a virtual DOM representation before converting to real DOM nodes.

This is a companion spec to hax-schema. Where hax-schema explains the full haxProperties contract for element authoring, this site focuses specifically on the element payload objects used in demoSchema, insertion, and conversion workflows.

Core shape

HAXElementSchema is an object with this shape:

Field reference

  • tag (required): HTML/custom-element tag name to create.
  • properties (optional): key/value map of attributes and/or properties.
  • content (optional): string content assigned as light DOM.
  • eventName (optional): event metadata added by insertion pipelines.
