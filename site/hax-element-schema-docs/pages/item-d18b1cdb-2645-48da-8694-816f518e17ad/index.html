hax-element-schema is one of several schema specifications in the HAX ecosystem. Explore the others:

  • JSON Outline Schema — the content structure, site navigation, and metadata schema used by HAXcms.
  • HAX Schema — the full haxProperties contract for element authoring.
  • Merlin Schema — the command-palette and voice-assistant Option/Program schema.
  • Appstore Spec — the schema for external media providers, upload targets, stax templates, and autoloaded elements.
