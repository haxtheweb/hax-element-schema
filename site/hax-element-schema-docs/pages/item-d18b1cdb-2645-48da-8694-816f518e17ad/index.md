hax-element-schema is one of several schema specifications in the HAX ecosystem. Explore the others:

*   [JSON Outline Schema](https://haxtheweb.github.io/json-outline-schema/) — the content structure, site navigation, and metadata schema used by HAXcms.
*   [HAX Schema](https://haxtheweb.github.io/hax-schema/) — the full haxProperties contract for element authoring.
*   [Merlin Schema](https://haxtheweb.github.io/merlin-schema/) — the command-palette and voice-assistant Option/Program schema.
*   [Appstore Spec](https://haxtheweb.github.io/appstore-spec/) — the schema for external media providers, upload targets, stax templates, and autoloaded elements.

New to HAX? [Get started with HAX](https://haxtheweb.org/).
